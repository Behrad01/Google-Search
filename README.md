# Google Search Clone

## About

This project is a recreation of Google's search pages using HTML and CSS. It includes a standard Google search page, an image search page, and an advanced search page.

The goal of this project was to practice building web pages, working with forms, and understanding how search queries are sent through URLs.

## Features

- Google-style search page
- Image search functionality
- Advanced search page
- Responsive page structure
- Custom CSS styling

## Technologies Used

- HTML
- CSS

## How It Works

The project uses HTML forms to send search queries to Google's search endpoints.

Different pages use different query parameters:

- Normal search sends a regular search query.
- Image search uses Google's image search option.
- Advanced search uses multiple filters for more specific searches.

## Installation

1. Clone this repository:

```bash
git clone https://github.com/Behrad01/Google-Search.git
```

2. Open `index.html` in your browser.

## Usage

Enter a search query and use the available search options to perform searches through the recreated interface.
